# Phase 17 development output; full submission gate open

The writer used the frozen development policy and the scored 1/16 test candidate manifest. It verified all 2,192,254 scored pairs, in order, against the exact final capped candidate Parquet and checked every target ID against the normalized sampled test S2/S3 IDs. It wrote 107,510 unique S1 rows to **each** TSV, including 4,044 S1 with no candidate. Matched IDs are always a subset of those scored candidates; duplicates, invalid references, model/policy mismatches, and incomplete scored shards are fatal.

The development predictions contain 79,842 zero-match, 20,369 one-match, and 7,299 multi-match entities, with 49,167 matched pairs total. Writing took 3.796 s, peaked at 0.385 GB RSS, and produced a 2.10 MB matching TSV and 29.65 MB candidate TSV. These counts describe unlabeled sampled test predictions, not accuracy.

The official `utils/validate_submission.py` logic ran with ID checks against a temporary TSV projection of the 107,510 sampled S1 IDs and 622,373 sampled S2/S3 IDs. It reported zero errors and zero warnings for both output files. The temporary projection is needed because the official validator expects raw TSV paths while the development test subset is cached as normalized Parquet. Hand tests cover singleton, one/many decisions, invalid scored pairs, duplicate IDs, nonexistent target references, and a matched-not-candidate subset violation, which the wrapper treats as fatal. All 45 tests passed.

**Not completed:** full-universe training and validation, 1,732,544-row test inference, actual AWS wall time and peak RSS, canonical `chimera_submission/output/` full-test files, and official validation against the complete raw test directory. The sample output under `artifacts/output/sample_16/` is deliberately separate from the submission directory. The pre-refit held-out development macro F0.5 is 0.885423, micro precision 0.985266 and recall 0.778656; these are optimistic because the development target universe has fewer distractors. Candidate recall is 0.794275 on the truth-complete development train sample, not on full training. Singleton false positives are 53/1,203 held-out true singletons. Full-universe measurements are still required before claiming completion.
