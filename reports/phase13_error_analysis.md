# Phase 13 — validation error analysis

The optimized Phase 12 policy was applied to all 20,825 held-out S1 entities in the corrected, truth-complete development sample. Error tags are non-exclusive: an S1 can have both missed true links and false extra links. The report retains deterministic examples with S1/target IDs, score, normalized name/address evidence, and country/cardinality slices. Only selected S1 and missing GT target rows are held in lookup tables; validation feature rows are processed one S1-hash shard at a time.

The largest limitation is retrieval. **16,151** GT links are absent from final candidates, while **1,107** retrieved GT links are left unselected by scoring/thresholds. Thus retrieval misses outnumber downstream misses by 14.6×. At entity level, 9,270 S1 have at least one retrieval miss, 9,580 multi-match S1 lack an extra predicted link, 1,031 have a retrieved true candidate left unselected, and 1,157 positive entities receive no predicted match. There are 42 singleton false positives, 35 wrong top candidates, and 23 cases where a retrieved true candidate ranks below a false top candidate.

Of the 16,151 missing links, 9,570 have normalized address RapidFuzz ratio at least 75, 7,306 share a house/building number, 6,681 have core-name ratio below 50, and 3,877 combine low name ratio with high address ratio. **1,335 have the exact same nonempty cleaned address**, a concrete target for cheap retrieval. Phase 14 will benchmark a frequency-aware exact-address channel with country/house refinement, then measure its unique GT recovery after the candidate cap, runtime/RAM, and final macro F0.5. These 1,335 are an upper bound before block and cap controls, not a promised gain. Global address TF-IDF remains deferred.

India accounts for 4,390 entities with retrieval misses among 8,269 held-out S1; 2,154 India entities show low-name/high-address evidence, versus 692 of 12,556 US S1. Representative India examples include Latin-script business names paired with Indic-script target names at strongly matching addresses. US misses more often retain substantial name similarity. Country mismatch and the narrow “raw nonempty, core empty” normalization failure subtype were zero in this audit; numeric/postal conflicts appeared in 389 entities, address conflicts in 583, and common-name ambiguity in 138. These tags guide later work but may overlap.

The analysis took 1.18 s and peaked at 0.62 GB RSS on the development sample. A full run requires scanning normalized target rows for only the missing GT IDs and processing validation features shardwise, keeping working sets bounded under the <10-GB phase target; actual AWS runtime and peak memory remain to be measured. Hand tests cover retrieval miss, singleton false positive, false top rank, common-name ambiguity, address conflict and postal/house conflict. The complete test suite passes.
