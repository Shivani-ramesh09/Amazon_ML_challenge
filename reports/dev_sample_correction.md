# Correction — entity-complete development training sample

The initial modulus-16 development run independently sampled S1 and target IDs. That kept only 29,999 of the 479,353 true links belonging to sampled S1 entities. Its Phase 3–10 recall and pair-model measurements remain historical engineering benchmarks, but its pseudo-singleton prevalence and entity oracle are invalid for model selection. They are superseded by this corrected sample. The code paths for normalization, blocking, retrieval, features, and scoring remain the same; only the development target row-selection policy changed. Full AWS mode is unchanged.

The revised normalization includes all S2/S3 IDs listed in the GT for selected train S1 entities, plus the original modulus-16 background target sample. It streams the source TSV and keeps memory bounded. The rebuilt sample has 138,401 S1 and 1,095,422 target rows (532,155 S2; 563,267 S3). A direct truth audit confirms **479,353 eligible of 479,353 original GT pairs, with zero S1 entities missing a true partner from the sample**. Target normalization took 11.1 s and 11.5 s, peaking at ~0.56 GB RSS. The set of linked target IDs contains 479,353 distinct IDs, and sample output row counts account for overlap with background targets.

Rebuilt exact, rare/numeric, and TF-IDF channels plus cap-30 union yield 2,895,797 final pairs and 372,430 GT pairs recovered: 77.69% pair candidate recall, 94.4% entity any-hit recall, 53.2% entity complete recall, and a 0.8915 entity macro F0.5 oracle. There are 7,827 true singletons, exactly the number with zero GT partners in this sample. The uncapped union recovers 373,563 pairs (77.93%). India cap-30 pair recall is 68.20%; US is 83.99%. Of 105,790 uncapped retrieval misses, 60,313 are India; 21,405 India misses have core-name ratio below 50 and address ratio at least 75. These are direct measurements in the corrected dev universe, not a full-universe production score.

Remaining limitation: the target background is still sampled, so common-name ambiguity and false candidates differ from full S2/S3. Thresholds and model choices found here must be checked on the full AWS universe before final freeze. The Phase 11–12 entity metric now has complete true sets and can be implemented without the earlier pseudo-singleton distortion.
